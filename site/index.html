Why help

Vamos is open source (AGPL-3.0) and a work in progress. You can help by labeling public Creative Commons (CC BY) clips, so the engine can learn who won each point.

Beat the Engine

Train your own point-winner model. We score it in a sandbox on a private test set. There is a public model leaderboard. Recognition only — no prizes.

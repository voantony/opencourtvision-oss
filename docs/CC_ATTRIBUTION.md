# CC attribution

No public clip is pinned yet. When you add one, append a block. CC0 needs a source line even though attribution is not a legal condition. CC BY must reproduce the credit the author asked for.

```
id:
title:
author:
url:
licence: CC0 | CC BY
sha256:
accessed:
```

Media bytes are downloaded by `scripts/fetch_public_clips.py` into a cache, not committed.

# Call the Point — spec

Engineering note, which takes precedence over the warm-up engine line in section 3.3 and section 8: the engine pick is shown only after a tap on a live point, including hidden checks. It is not shown on warm-up points. Share cards use the live address `https://opencourtvision-10a09b.gitlab.io`.

English name: **Call the Point**. Spanish name: **¡Canta el punto!**.

A is always the near side of that clip. B is always the far side. The legend is static: **A: near side · B: far side** / **A: lado cercano · B: lado lejano**. It never flips. Do not say “near team”, “far team”, or ask the player to follow shirt colour.

The third button stays **Fault serve** / **Saque falta**, with the subtitle **Serve doesn't count (fault or let)** / **El saque no cuenta (falta o let)**.

Warm-up order is p4 (near side won), p3 (let), p5 (far side won), from public CC BY video 2p6PcKP0720. After a correct tap the screen says Correct / Correcto and the reason. It does not show the engine. The p3 reasons are:

- EN: Let: the serve clipped the net and landed in, so it's replayed and no point is scored.
- ES: Let: el saque toca la red y entra, se repite y no hay punto.

Those three clip ids never enter a round, scoring, or the human baseline. Every other session-01 clip now has `a_side_team`, so 43 clips are playable.

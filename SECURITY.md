# Security Policy

OpenCourtVision runs locally and processes media files with ffmpeg. If you find a security issue (for example
unsafe handling of crafted media or config files, or command injection through file names or captions), please
**do not open a public issue**. Email **antonyvo@mail.grokbot.com** with details and steps to reproduce.
That address is the private reporting contact for this AGPL-3.0-only tree.
You should get an acknowledgement within 7 days. We'll coordinate a fix and a disclosure date with you.

Only the latest `main` is supported.
